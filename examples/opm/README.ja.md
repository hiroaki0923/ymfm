# YM2151 OPM サンプル

このディレクトリには、ymfmライブラリのYM2151（OPM）FM音源チップエミュレーションを実演するサンプルコードが含まれています。これらのサンプルは、実際の音声生成を通じてOPMプログラミングの概念を学習したい方の参考になるかもしれません。

## 概要

YM2151（OPM - FM Operator Type-M）は、アーケード基板、Sharp X68000コンピュータ、各種シンセサイザーで使用された4オペレータFM音源チップです。このサンプル集では、ymfmライブラリを使用してOPMパラメータを設定し、様々な音色や音楽効果を生成する一つのアプローチを示しています。

## 内容

これらのサンプルには以下が含まれています：

- **音声出力**: 各デモでは聞くことができるWAVファイルを生成します
- **パラメータ例**: レジスタ設定のサンプルとその音への影響
- **段階的なサンプル**: シンプルなサイン波から多チャンネル楽曲まで
- **参考コード**: ご自身のプロジェクトで参考となるコメント付きソースコード

## デモプログラム

サンプルジェネレータは8つの個別WAVファイルを作成し、それぞれパラメータの効果をわかりやすくデモします：

### 基本的な音生成

**01_sine_wave_scale.wav** - 純粋なサイン波スケール
- 基本的なOPMセットアップと音階周波数計算
- シンプルなサイン波音色（アルゴリズム7、単一オペレータ）
- ピッチ制御のためのKC/KFレジスタプログラミング
- OPM基礎理解の出発点

**02_piano_scale.wav** - ピアノ風音色のスケール
- 複数オペレータによるFM音源
- アルゴリズム選択と音色への影響
- 打楽器的サウンドのためのエンベローププログラミング
- サイン波との比較によるFMの複雑さの表現

**03_twinkle_twinkle_chords.wav** - 多チャンネル和音進行
- 4チャンネル編成：メロディ、ベース、2つの和音声部
- 音楽的役割に応じた異なる音色
- 複数チャンネルの協調
- 基本的な和声編成

### OPM制御デモンストレーション

**04_lfo_effects.wav** - LFO（低周波発振器）エフェクト
- クリーンサウンド vs ビブラート vs トレモロの比較
- PMS設定によるピッチモジュレーション（ビブラート）
- AMS設定によるアンプリチュードモジュレーション（トレモロ）
- シンセサイズドサウンドへの表現力追加

**05_fm_algorithms.wav** - FMアルゴリズム比較
- アルゴリズム0、1、4、7の並列比較
- オペレータルーティングと倍音構成への影響
- アルゴリズムが異なる音響特性を生む仕組み
- FM音源の基礎

**06_envelope_control.wav** - ADSRエンベロープバリエーション
- アタック、ディケイ、サスティン、リリースの各段階
- 打楽器的 vs パッド的エンベロープ設定
- エンベロープタイミングが音楽的表現に与える影響
- 様々な楽器音の作成

**07_detune_effects.wav** - 音の厚みのためのデチューン
- 段階的なデチューン（DT1）エフェクト
- わずかな周波数オフセットがコーラスや厚みを生む仕組み
- 薄い音と豊かな音の違い
- より充実したシンセサイザーサウンドの作成

### 高度なテクニック

**08_stereo_arpeggiator.wav** - スムースステレオアルペジエーター
- ダイナミックパンニングを伴う16秒のステレオ楽曲
- 異なるコード進行による4チャンネルアルペジエーター
- スムースな音の遷移とエンベロープ管理
- ステレオポジショニングと音楽編成
- ヘッドフォンでお聞きいただくとより効果的

## サンプルのビルド

### 必要環境

- C++17対応コンパイラ（GCC、Clang、MSVC）
- ymfmライブラリソースファイル（`../../src/`に含まれています）

### ビルドオプション

#### Makeの使用

```bash
# examples/opm ディレクトリから
make                 # サンプルジェネレータをビルド
make run             # ビルドして実行
make clean           # 生成ファイルを削除
```

#### 手動コンパイル

```bash
# 全ソースファイルのコンパイル
g++ -std=c++17 -O2 -Wall -I../../src \
    opm_sample.cpp opm_common.cpp \
    01_sine_wave_scale.cpp 02_piano_scale.cpp 03_twinkle_twinkle_chords.cpp \
    04_lfo_effects.cpp 05_fm_algorithms.cpp 06_envelope_control.cpp \
    07_detune_effects.cpp 08_stereo_arpeggiator.cpp \
    ../../src/ymfm_opm.cpp \
    -o opm_sample
```

## サンプルの実行

コンパイル済みプログラムを実行して全デモファイルを生成：

```bash
./omp_sample
```

**出力**: プログラムは現在のディレクトリに8つのWAVファイル（44.1kHz、16ビットステレオ）を生成します：

- `01_sine_wave_scale.wav` - シンプルなサイン波デモンストレーション
- `02_piano_scale.wav` - ピアノ風FM音源
- `03_twinkle_twinkle_chords.wav` - 多チャンネル音楽編成
- `04_lfo_effects.wav` - ビブラートとトレモロエフェクト
- `05_fm_algorithms.wav` - アルゴリズム比較
- `06_envelope_control.wav` - ADSRエンベロープバリエーション
- `07_detune_effects.wav` - デチューンとコーラスエフェクト
- `08_stereo_arpeggiator.wav` - 高度なステレオ楽曲

**リスニングメモ**:
- `08_stereo_arpeggiator.wav`のステレオエフェクトはヘッドフォンで聞くとより効果的です
- 順番に聞くことで段階的な複雑さを理解できるかもしれません
- 似たようなデモ（01と02、05の異なるアルゴリズム）を比較すると違いが分かりやすいです

## コード構造

### コアファイル

- **`omp_sample.cpp`** - 全デモンストレーションを統括するメインプログラム
- **`opm_common.h/.cpp`** - 共有ユーティリティと音色定義
  - 音声ユーティリティ（WAV書き込み、サンプリングレート変換）
  - 音楽ユーティリティ（音階-周波数変換、OPM周波数計算）
  - 音色プリセット（サイン波、ピアノ、ベース、コード、シンセ音）
  - YM2151インターフェース実装

### 個別デモファイル

各`0X_*.cpp`ファイルには特定の学習目標を持つデモンストレーションが含まれています：
- 特定の教育目標を持つ自己完結型関数
- OPMレジスタ設定を説明する詳細なコメント
- 基本から高度まで段階的な複雑さ

### サンプルコードに含まれる主な内容

1. **レジスタプログラミング**: 直接的なYM2151レジスタ操作
2. **音色設計**: オペレータ設定が異なる音をどのように作るか
3. **周波数制御**: KC/KFレジスタ計算と使用法
4. **エンベローププログラミング**: ADSRエンベロープ設定
5. **多チャンネル協調**: 複数音声の同時管理
6. **リアルタイムパラメータ変更**: 動的な音の変更

## 技術的な注意事項

- **サンプリングレート**: YM2151は約3.579MHzで動作し、出力は44.1kHzにリサンプリングされます
- **ビット深度**: 16ビット符号付きステレオ出力
- **レイテンシ**: ゼロレイテンシの直接音源（オーディオドライバなし）
- **互換性**: 純粋なC++実装、クロスプラットフォーム対応
